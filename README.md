# 📝 Task Management Application (MERN Stack)

## 📖 Description

Application web pour gérer les tâches des employés.  
Projet réalisé dans le cadre de fin de module MERN Stack.

## 🧩 Technologies

- **Frontend :** React, Axios
- **Backend :** Node.js, Express, MongoDB
- **Auth :** JWT, bcrypt

## ⚙️ Fonctionnalités

- Inscription / Connexion utilisateur
- CRUD des tâches
- Filtrage par statut
- Interface responsive
